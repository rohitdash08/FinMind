# Deploy FinMind Frontend on Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/rohitdash08/FinMind&root-directory=app)

## Setup

1. Click Deploy button or `vercel --cwd app`
2. Set root directory: `app`
3. Set environment variable: `VITE_API_URL=https://your-backend-url`
4. Deploy

## CLI

```bash
cd app
npx vercel --prod
```
