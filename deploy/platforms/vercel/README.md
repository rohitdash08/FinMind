# Deploy FinMind Frontend to Vercel

## One-Click Deploy
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/rohitdash08/FinMind&root-directory=app)

## Setup
1. Import your GitHub repo on [Vercel](https://vercel.com)
2. Set Root Directory to `app/`
3. Framework Preset: Vite
4. Add environment variable `VITE_API_URL` pointing to your backend

## Notes
- Deploys the frontend SPA only
- Automatic HTTPS, CDN, and preview deployments
- Backend must be deployed separately
