## 使用示例
```python
from bank_connector import ConnectorManager, BankType

# 创建管理器
manager = ConnectorManager()

# 创建模拟连接器
connector = manager.create_connector(
    bank_type=BankType.MOCK,
    config={'name': 'Test Bank'}
)

# 连接并同步
connector.connect()
accounts = connector.sync_accounts()
transactions = connector.sync_transactions()

connector.disconnect()
```
